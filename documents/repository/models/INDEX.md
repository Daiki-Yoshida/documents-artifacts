# Repository Models

この領域は、dev-artifactsの**管理モデル**を所有する。

対象は知識の保存・整理・制定と承認、意味・評価の追跡、各領域の責務と所有権のような、実行手段に依存しない管理契約である。Dev-Philosophyの内容はここで定義せず、`documents/knowledge/subjects/dev-philosophy/` にOwner承認済みの正本として置く。

現時点では配置と責務の採用のみ。旧 `documents/knowledge/system/` の各モデルの移設・分割・見直し、承認条件の詳細はStage 1の残作業であり、ここへ無審査でコピーしない。
