# Repository Models

この領域はdev-artifactsリポジトリの**管理契約**を所有する。Dev-PhilosophyやDev-Methodologyの内容自体はここで制定しない。

| 文書 | 定義権 |
| --- | --- |
| [DEV_LAYERS_MODEL](DEV_LAYERS_MODEL.md) | 3層、固定用語、層の前提関係 |
| [AUTHORITY_GOVERNANCE_MODEL](AUTHORITY_GOVERNANCE_MODEL.md) | 概念の定義権、Owner承認、規範優先と情報源判断の区別 |
| [KNOWLEDGE_MODEL](KNOWLEDGE_MODEL.md) | 情報源・正本・派生物の責務と境界 |
| [RECORD_MODEL](RECORD_MODEL.md) | source eventと原文記録の保存契約 |
| [DECISION_LINEAGE_MODEL](DECISION_LINEAGE_MODEL.md) | 記録された判断の関係、scope、現在評価 |
| [SUBJECT_MODEL](SUBJECT_MODEL.md) | subjects正本の基本責務。具体的抽出はStage 2 |
| [TRACEABILITY_MODEL](TRACEABILITY_MODEL.md) | 正本から原文根拠へ戻る契約 |

- 管理モデルの**実施手順**は [operations](../operations/INDEX.md) が所有する。
- 旧モデル全文は [legacy](../legacy/INDEX.md) に参考資料として保存する。こちらを現行規則として再採用しない。
- Artifactsの投影・読み込み・配布の規則はStage 3で制定する。旧Artifact v2の `selective routing` は現行契約として継承しない。
