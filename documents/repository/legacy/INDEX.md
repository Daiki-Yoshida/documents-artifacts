# Legacy reference materials — Non-current

ここは`documents-artifacts`時代の管理文書・Artifact v2設計・監査・実験資料を**内容を変更せずに**保持した比較用領域である。

- `system/`: 旧`documents/knowledge/system/`のsnapshot。旧Artifact Model、旧Subject Modelを含む。
- `project/`: 旧`documents/project/`の、移行・レビュー・テストハーネス等の参考資料。
- 旧`KNOWLEDGE_UPDATE_WORKFLOW.md`や`REPOSITORY_STRUCTURE.md`の旧本文はGit履歴と分岐元`main`から参照できる。
- ここにある旧`selective routing`や`Artifact v2`の指示は、**現在の設計・運用規則として効力を持たない**。
- 原文としての判断経緯は`documents/knowledge/records/`が保持する。legacyは原文recordの代わりにはならない。
- 旧pathを含む相対リンクやコマンド例は歴史的な文面であり、この場所で実行・解決できることを保証しない。

現在有効な管理契約は[models](../models/INDEX.md)、実施手順は[operations](../operations/INDEX.md)を確認する。
