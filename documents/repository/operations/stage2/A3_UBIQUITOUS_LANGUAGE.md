## 基礎用語

以下の説明は読者が語の意味を取り違えないための索引であり、[草案本文](A3_PHILOSOPHY_DRAFT.md)での定義を置き換えたり新しい条件を追加したりしない。

| 用語 | 参照する意味・区別 | 定義・説明箇所 |
| --- | --- | --- |
| **まとまり** | 主体が、何を一つとして何として扱うかを定める仮想的な存在 | [D1.1](A3_PHILOSOPHY_DRAFT.md#d1-1) |
| **定義** | まとまりを何として扱うかを定めること | [D1.2](A3_PHILOSOPHY_DRAFT.md#d1-2) |
| **命名** | 文字列だけでなく、その存在を何として認識・定義するかを表す側面 | [D1.2](A3_PHILOSOPHY_DRAFT.md#d1-2) |
| **本質** | 実態そのものではなく、定義された仮想的なまとまりが何であるかという意味 | [D1.2](A3_PHILOSOPHY_DRAFT.md#d1-2) |
| **抽象** | 特定の具象を決めずに、まとまりの意味を扱う側面 | [D1.2〜D1.3](A3_PHILOSOPHY_DRAFT.md#d1-3) |
| **境界** | その存在として引き受ける範囲 | [D1.2](A3_PHILOSOPHY_DRAFT.md#d1-2) |
| **主体** | ある関わりで対象を捉え、定義し、判断する立場。現実の個体と同一ではない | [D2.1](A3_PHILOSOPHY_DRAFT.md#d2-1) |
| **担い手** | 主体を担う存在。個人だけでなく組織等の集合体も一つのまとまりとなり得る | [D2.4](A3_PHILOSOPHY_DRAFT.md#d2-4) |
| **基点主体** | 現在のコンテキストで主軸となる直接的な欲求に対応する主体。絶対的最上位ではない | [D2.4](A3_PHILOSOPHY_DRAFT.md#d2-4) |
| **欲求** | 主体がその存在に何を求めるか | [D2.2](A3_PHILOSOPHY_DRAFT.md#d2-2) |
| **責務** | その欲求に応えるものとしてまとまりが引き受けること | [D2.2〜D2.3](A3_PHILOSOPHY_DRAFT.md#d2-2) |
| **開発対象** | 当該主体が成立させようとするまとまり | [D2.4](A3_PHILOSOPHY_DRAFT.md#d2-4) |
| **契約** | その存在の名前＝本質＝境界と、他の存在への関わり方を定める仮想側の定義 | [D3.1](A3_PHILOSOPHY_DRAFT.md#d3-1) |
| **契約の成立** | 対象となる存在以外の異なる存在との合意のもとで契約が形成されること | [D3.2](A3_PHILOSOPHY_DRAFT.md#d3-2) |
| **契約の履行** | 実態が、その存在の契約と乖離していないかという対応 | [D3.3](A3_PHILOSOPHY_DRAFT.md#d3-3) |
| **内部自由** | ある主体の定義・契約で規定しない内側に成立する自由 | [D3.4](A3_PHILOSOPHY_DRAFT.md#d3-4) |
| **境界の双璧** | 主体の欲求が定めるマクロ側の壁と、委譲・依存先へ接続するミクロ側の壁 | [D5.2](A3_PHILOSOPHY_DRAFT.md#d5-2) |
| **分割の幅** | 基点主体の側から各枝の委譲・依存先まで、当該開発で扱う範囲 | [D5.1〜D5.3](A3_PHILOSOPHY_DRAFT.md#d5-3) |
| **分割の粒度** | 扱う範囲の内側を、どの細かさ・構造で区切るか | [D5.3](A3_PHILOSOPHY_DRAFT.md#d5-3) |
| **分割圧／統合圧** | 責務の独立と内部自由を考え、区切る方向・一体として担う方向の理由を捉える語 | [D5.4](A3_PHILOSOPHY_DRAFT.md#d5-4) |
| **分割停止** | その階層の内部をさらに独立契約へ分けず、一体として引き受けること | [D5.5](A3_PHILOSOPHY_DRAFT.md#d5-5) |
| **委譲** | 区切った責務を別の主体へ任せること。分割停止とは異なる | [D2.3](A3_PHILOSOPHY_DRAFT.md#d2-3)・[D5.5](A3_PHILOSOPHY_DRAFT.md#d5-5) |
| **乖離** | どの主体のどの定義・契約かを特定したうえで捉える、仮想側と実態側のずれ | [D4.2](A3_PHILOSOPHY_DRAFT.md#d4-2)・[D6.1](A3_PHILOSOPHY_DRAFT.md#d6-1) |
| **再定義** | まとまりの境界を区切り直すこと。実態の変化だけから自動的に必要とはならない | [D6.3](A3_PHILOSOPHY_DRAFT.md#d6-3) |

**定義・命名・意味／本質・抽象・契約・境界は一つの営みの異なる側面**であり、表の行数だけ独立した工程が存在するわけではない。契約の内容・成立・履行は異なる問いとして扱う。

## 採用した性質の参照名

| 名称 | 種別 | 対象 |
| --- | --- | --- |
| **定義の一体性** | 概念関係の参照名 | 定義・命名・本質・抽象・契約・境界を一つの存在の定義の異なる側面として扱う。[D1.2](A3_PHILOSOPHY_DRAFT.md#d1-2) |
| **内部自由の契約相対性** | 性質の参照名 | 自由となる内部の範囲が、主体とその定義・契約によって異なる。[D3.4](A3_PHILOSOPHY_DRAFT.md#d3-4) |
| **まとまりの仮想性** | 既存の性質の説明名 | 一つのまとまりが主体から独立した唯一の区切りとして存在するわけではない。[D1.1](A3_PHILOSOPHY_DRAFT.md#d1-1) |
| **基点主体の相対性** | 既存の性質の説明名 | どの主体が基点となるかは現在のコンテキストと欲求に応じる。[D2.4](A3_PHILOSOPHY_DRAFT.md#d2-4) |

「内部自由の契約相対性」は**原則名ではなく性質名**である。二つの参照名を新たな規範・義務として扱わない。

## 理論と、独立した名前を付けない説明

- **境界面理論**は既存の理論名として維持する。その内側に**境界の双璧**・基点主体・分割圧／統合圧などの語を置くが、枝ごとに異なるミクロ側の壁を別の理論へ独立させない。
- **フラクタル性**は再帰的な構造の説明語であり、数学的なフラクタル構造が証明されたとの主張に強めない。
- **白いキャンバス・汚れた窓**、**樹・幹・枝**は説明上の比喩として保持し、独立した原則・理論名は付けない。
- **契約／契約の成立／契約の履行**は三つの語をそのまま使い、別の総称や強制的な工程名を追加しない。
- **乖離事情のA／B／C分類**は原因の例示であって、すべてを尽くす分類規格へ変えない。
- **定義の脱皮**は既存の比喩として保持し、別の必須工程を意味させない。
- **責務の内包と収束**はD2.3の説明句として使えるが、独立した法則名にはしない。
- **再定義論**は正式な独立理論名として今回追加しない。再定義は第6章「乖離と再定義」の範囲で扱う。
