# 契約境界哲学体系 — 採用された用語・命名の参照表

**状態：Stage 2-A-3の命名に関するOwner採用範囲を整理した資料。** これは[契約境界哲学体系草案](A3_PHILOSOPHY_DRAFT.md)の用語索引であり、独立した定義の正本や開発哲学全文の正式制定ではない。詳細な意味、条件、例は草案の該当節を参照する。

[Ownerの用語・章名の採用判断](../../../knowledge/records/2026-11-14-contract-boundary-terminology-approval/RECORD.md)により、既存用語・章名・性質の参照名と、不必要な命名を増やさない方針が採用された。さらに[後続のOwner判断](../../../knowledge/records/2026-11-14-contract-boundary-principle-unification/RECORD.md)によって、**契約境界哲学体系それ自体を原則とし、内部の個々の判断指針に独立した原則名や英語略称を設けない**ことが定まった。

[認識・情報化に関する後続の対話](../../../knowledge/records/2026-11-14-recognition-information-and-virtuality-philosophy-baseline/RECORD.md)を受けて、草案D1.1・D1.3・D2.2・D4.2の説明を補強した。ただし、**「仮想」と「情報化」の名称関係についてOwnerの最終的な用語判断はまだない**ため、下記では採用済みの用語と検討中の説明を区別する。

## 基礎用語

以下の説明は読者が語の意味を取り違えないための索引であり、[草案本文](A3_PHILOSOPHY_DRAFT.md)での定義を置き換えたり新しい条件を追加したりしない。

| 用語 | 参照する意味・区別 | 定義・説明箇所 |
| --- | --- | --- |

| **定義** | まとまりを何として扱うかを定めること | [D1.2](A3_PHILOSOPHY_DRAFT.md#d1-2) |
| **命名** | 文字列だけでなく、その存在を何として認識・定義するかを表す側面 | [D1.2](A3_PHILOSOPHY_DRAFT.md#d1-2) |
| **本質** | 実態そのものではなく、定義された仮想的なまとまりが何であるかという意味 | [D1.2](A3_PHILOSOPHY_DRAFT.md#d1-2) |
| **抽象** | 特定の具象を決めずに、まとまりの意味を扱う側面 | [D1.2〜D1.3](A3_PHILOSOPHY_DRAFT.md#d1-3) |

| **担い手** | 主体を担う存在。個人だけでなく組織等の集合体も一つのまとまりとなり得る | [D2.4](A3_PHILOSOPHY_DRAFT.md#d2-4) |
| **基点主体** | 現在のコンテキストで主軸となる直接的な欲求に対応する主体。絶対的最上位ではない | [D2.4](A3_PHILOSOPHY_DRAFT.md#d2-4) |
| **欲求** | 主体がその存在に何を求めるか | [D2.2](A3_PHILOSOPHY_DRAFT.md#d2-2) |

| **契約** | その存在の名前＝本質＝境界と、他の存在への関わり方を定める仮想側の定義 | [D3.1](A3_PHILOSOPHY_DRAFT.md#d3-1) |
| **契約の成立** | 対象となる存在以外の異なる存在との合意のもとで契約が形成されること | [D3.2](A3_PHILOSOPHY_DRAFT.md#d3-2) |
| **契約の履行** | 実態が、その存在の契約と乖離していないかという対応 | [D3.3](A3_PHILOSOPHY_DRAFT.md#d3-3) |
| **内部自由** | ある主体の定義・契約で規定しない内側に成立する自由 | [D3.4](A3_PHILOSOPHY_DRAFT.md#d3-4) |
| **境界の双璧** | 主体の欲求が定めるマクロ側の壁と、委譲・依存先へ接続するミクロ側の壁 | [D5.2](A3_PHILOSOPHY_DRAFT.md#d5-2) |
| **分割の幅** | 基点主体の側から各枝の委譲・依存先まで、当該開発で扱う範囲 | [D5.1〜D5.3](A3_PHILOSOPHY_DRAFT.md#d5-3) |
| **分割の粒度** | 扱う範囲の内側を、どの細かさ・構造で区切るか | [D5.3](A3_PHILOSOPHY_DRAFT.md#d5-3) |
| **分割圧／統合圧** | 責務の独立と内部自由を考え、区切る方向・一体として担う方向の理由を捉える語 | [D5.4](A3_PHILOSOPHY_DRAFT.md#d5-4) |

**定義・命名・意味／本質・抽象・契約・境界は一つの営みの異なる側面**であり、表の行数だけ独立した工程が存在するわけではない。契約の内容・成立・履行は異なる問いとして扱う。

## 採用した性質の参照名

| 名称 | 種別 | 対象 |
| --- | --- | --- |
| **定義の一体性** | 概念関係の参照名 | 定義・命名・本質・抽象・契約・境界を一つの存在の定義の異なる側面として扱う。[D1.2](A3_PHILOSOPHY_DRAFT.md#d1-2) |

## 後続の認識・情報化の対話による補足（用語の採用範囲に注意）

本節は、[新しい哲学baseline](../../../knowledge/records/2026-11-14-recognition-information-and-virtuality-philosophy-baseline/RECORD.md)のOwner U1〜U4を参照し、現在の草案に追加した説明の入口を示す。「情報化」という名称への全面移行を採用済みと宣言するものではない。

| 対象 | 今回明示した区別 | 草案 |
| --- | --- | --- |
| **仮想的なまとまり** | 未完成の実物や未決定の実現方式を指すのではない。特定個体についても、主体が思考・言及する際に掴むのは認識側の対象である | [D1.1](A3_PHILOSOPHY_DRAFT.md#d1-1) |
| **認識・情報** | 実体そのものと、実体・経験を認識して情報として思考・言及することは同一ではない。「認識＝情報」は今回のOwnerが提起した表現であり、既存の「仮想」との語の置換関係は検討中 | [D1.1](A3_PHILOSOPHY_DRAFT.md#d1-1)・[D4.2](A3_PHILOSOPHY_DRAFT.md#d4-2) |
| **実体験** | 熱さや味を直接感じることを否定しない。その体験を後に「熱かった」と記憶し言及するとき、直接扱うのは認識された情報である | [D1.1](A3_PHILOSOPHY_DRAFT.md#d1-1) |
| **欲求・本質・定義** | 「時刻を知りたい」から「時刻が分かるもの」という意味のまとまりを定義することは、具象的な製品や方式を選ぶ工程ではない | [D2.2](A3_PHILOSOPHY_DRAFT.md#d2-2)・[D1.3](A3_PHILOSOPHY_DRAFT.md#d1-3) |

なお、今回のOwner発言で提起された「情報化」「認識＝情報」は、既存の「仮想」を全面置換する採用済み用語ではなく、用語関係を検討中の説明候補である。現時点の草案では「認識された情報」を、主体が実体・体験について思考・言及するときに扱う内容を指す説明語として用いる。これは、神経活動・記憶の物理的状態と情報内容を同一視したり、実体自体が情報へ変質すると述べたりするものではない。

また、**認識された情報と仮想的なまとまりを独立した存在階層や前後の工程として扱わない**説明を草案へ追加した。これはS17のOwner原文を接続したAssistant編集案であり、Ownerの逐語的な定義として扱わない。特定個体への言及にも認識が介在すること、体験と体験についての情報を思考・言及することを区別する点はOwner原文に基づく。詳細は[S17の出典対応](A3_PHILOSOPHY_REVIEW.md#s17)と[L06](A3_PHILOSOPHY_REVIEW.md#l06)を参照する。

## 理論と、独立した名前を付けない説明

- **境界面理論**は既存の理論名として維持する。その内側に**境界の双璧**・基点主体・分割圧／統合圧などの語を置くが、枝ごとに異なるミクロ側の壁を別の理論へ独立させない。
- **フラクタル性**は再帰的な構造の説明語であり、数学的なフラクタル構造が証明されたとの主張に強めない。
- **白いキャンバス・汚れた窓**、**樹・幹・枝**は説明上の比喩として保持し、独立した原則・理論名は付けない。
- **契約／契約の成立／契約の履行**は三つの語をそのまま使い、別の総称や強制的な工程名を追加しない。
- **乖離事情のA／B／C分類**は原因の例示であって、すべてを尽くす分類規格へ変えない。
- **定義の脱皮**は既存の比喩として保持し、別の必須工程を意味させない。
- **責務の内包と収束**はD2.3の説明句として使えるが、独立した法則名にはしない。
- **再定義論**は正式な独立理論名として今回追加しない。再定義は第6章「乖離と再定義」の範囲で扱う。

## 契約境界哲学体系そのものを原則として扱う

**本体系そのものを原則とし、その内部を個別の「○○原則」に分立させない。** 各節にある規範的な判断指針、定義、性質、理論は、それぞれの内容と役割のまま保持する。独立した原則名・英語の副名称・略称を設けないことは、内部の指針を撤回する意味ではない。

この位置づけは[Ownerの後続判断](../../../knowledge/records/2026-11-14-contract-boundary-principle-unification/RECORD.md)による。以前の命名案・検討経緯は先行recordとGit履歴から辿り、現在の用語索引には再掲しない。

この資料は**体系名・用語・章名・性質の参照名と、下位の独立原則名を設けない命名方針**を扱う。体系本文の全文や実務方法論の正式制定を宣言するものではない。
