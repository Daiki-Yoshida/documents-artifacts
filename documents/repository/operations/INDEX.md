# Repository Operations

この領域は、`../models/` の管理契約を前提として、**このリポジトリでの具体的な運用手順**を所有する。

対象例は知識更新の実務、GitHub運用、移行、検証、監査やリポジトリ固有のスクリプト連携である。方法論の内容そのものやmodelsの意味をここで再定義しない。

旧 `documents/project/` の運用文書・監査資料は移行元に保持している。各文書の配置と参照修正は検証しながら段階的に行う。
