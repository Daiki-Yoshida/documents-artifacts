# Repository Operations

`documents/repository/operations/` は、[models](../models/INDEX.md) が所有する管理契約を前提に、リポジトリ固有の実施手順・検証を所有する。

- [Knowledge Update Workflow](KNOWLEDGE_UPDATE_WORKFLOW.md)：source eventの取り込み、Owner承認の扱い、Stage境界、変更管理。
- 新しい抽出手順はStage 2、Artifact射影・配布手順はStage 3で制定する。旧Artifact v2の運用を暗黙に再採用しない。
- 過去の移行・監査・Agentテスト資料は[legacy](../legacy/INDEX.md)に保存する。

ここでモデルの意味を別個に定義しない。
