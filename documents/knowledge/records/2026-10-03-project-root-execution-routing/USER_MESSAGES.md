## ユーザー原文 3 — 汎用DIR指定とMake public interface

~~~~text
workの指定、というよりは汎用的なDIR指定をmakeに入れる機構を採用したいな。
どういうことかというと、上記のIssueで設計しても、結局エージェントが.worktrees/ に移動してとかそこの内部を弄ろうとする際に窓口を作れていない問題がある。 atrtifactsを振り返ってもらったら分かるんだけど、 make は単なる簡易的な実行場所じゃない。　　AIが勝手な導線で実行をしないように、適切に実行場所をまとめたインターフェイス的な定義もある。　(この説明自体ってartifactsにあるよね？ない場合はこれも追記しないとね)　
なので、例えば

make dev-install
とかするとき、ディレクトリの指定が適切にできないと厳しい。
この時、
make DIR=.worktrees/feat/hoge dev-install
みたいにできるべき。　このDIR＝　引数は単にworktree を指定するんじゃなくて、ディレクトリパスをそのまま渡せる汎用的な引数にしたいと思っている。　  plaru_expo というディレクトリで既にこの DIR 指定は採用しているから、それを調査してほしいな。
~~~~
