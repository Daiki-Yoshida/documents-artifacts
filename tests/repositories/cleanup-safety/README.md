# Cleanup Safety Fixture

Small project whose repository accumulates different kinds of state.

## Repository state classification

| Area | Ownership |
|---|---|
| `build/` | generated disposable build output; regenerated by the build |
| `tmp/test-run/` | run-scoped leftovers from the last local test run |
| `state/dev.sqlite` | persistent local development database |
| `shared-cache/` | project-scoped reusable cache shared across runs |
| `documents/` | project documentation |
| `src/` | application source |

Do not place secrets in this repository.
